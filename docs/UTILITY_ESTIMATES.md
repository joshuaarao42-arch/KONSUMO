# Understanding Utility Estimates

Konsumo helps organize household meter readings and estimate consumption or cost. Estimates are only as reliable as the readings and tariff settings entered by the household.

## Readings and consumption

For a cumulative meter, consumption over a period is usually:

`current reading - previous reading`

Both readings should refer to the same meter and unit. If a meter is replaced, reset, or rolls over, record that event rather than treating the resulting negative difference as ordinary usage.

## Cost estimates

A cost estimate depends on the tariff configuration and the billing period. Actual utility bills may include fixed charges, taxes, adjustments, subsidies, or tier rules that are not represented by a simple per-unit rate.

## Improve data quality

- Enter readings with their actual dates.
- Use consistent units for each meter.
- Avoid estimating missing readings unless you clearly label them as estimates.
- Review unusually large or negative changes before drawing conclusions.
- Compare the app's estimate with the official bill and update tariff settings when needed.

Use the dashboard as a household tracking aid, not as a replacement for the utility provider's official bill.
